Roof Cut Planner

16 mm multiwall polycarbonate. Flutes run down the slope, so pieces are placed as-is or turned a half turn (↻) — never a quarter turn, never mirrored.

Data

Sheet prices are Axiome Clear 16 mm from clearambershop, read 28 Aug 2026, inc VAT. Every size is £20.20/m², so offcut costs the same whatever you buy.

Type the measurements into the boxes under each piece and they save to data/cuts.json as you leave the box — or edit the file, and the drawing follows within a second. Saving to the file needs node serve.mjs; anywhere else the measurements are kept in this browser instead, and loaded back ahead of the file next time — “Use the file again” throws that copy away. A green border means the lengths close into a real piece, red that they do not and the drawing is the nearest that does. All values are in cm. Edges go clockwise from the bottom-left corner and numbered from there: [side 1, side 2, side 3, side 4] for 4 sides, [side 1, side 2, side 3] for 3. The last one is always the base — the edge that sits on the eave.
